          The hall of fame

          Ask the hall to restart the server

          This files a request. It does not restart anything. The request goes to Discord, where someone with the keys has to approve it — nothing happens until they do.

          Nothing checks this. The page cannot prove who you are, and whoever approves it is told as much.

          The world is saved before the server stops, so nothing anyone built is lost. It is usually back within a couple of minutes, though it can take up to about fifteen if Steam has an update waiting to install. Anyone in the world gets no warning at all — this server runs no mods and vanilla Valheim gives the server no way to speak to players, so the countdown only reaches Discord and this page.
